# 露營場排班規劃

31 帳露營場的全日排班規劃，單一 HTML 檔，無外部相依。

**線上版**：https://jimbo90015.github.io/camp-shift-plan/

## 內容

10 個模塊：編制總覽、30 天輪休表、全日流程圖（可點、可切換情境）、房務試算、
接駁車、園藝、交接點、缺席代班、決策紀錄、待辦。

- 22 個職務位（正職 18 ＋ 工讀 4）
- 常態日 20 天／餘裕日 8 天／休園日 2 天
- 接駁車 5 台、房務兩人一組每帳 19.8 分鐘

## 注意

- 頁面帶 `noindex, nofollow`，不希望被搜尋引擎收錄
- 房內單帳工時、車輛載客規格、洗碗機批次三個數字尚未實測，表上的時間是估算
- 輪休表是範例，證明排得出來；實際排班要疊上個人請假需求
